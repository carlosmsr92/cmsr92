## Tecnología

HTML, CSS y JavaScript sin frameworks, publicado con GitHub Pages. Tema claro y oscuro (sigue al sistema y se puede
cambiar con el botón), diseño adaptado a móvil, tipografía Inter e iconos de Font Awesome.

```
cmsr92/
├── index.html        # Página
├── styles.css        # Estilos y temas
├── script.js         # Tema, navegación y animaciones
├── images/           # Capturas de los proyectos, favicon e imagen para redes sociales
└── brand-assets/     # Logo en sus variantes y guía de marca
```
